# Contributing

Obrigado por contribuir com o VISAT Manager.

## Ambiente de Produção

Frontend:
https://visat-manager.vercel.app/

Backend:
https://visat-manager-backend.onrender.com/

## Execução Local

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
pip install -r requirements.txt
python app.py
```

## Processo de Contribuição

1. Criar uma branch para a alteração.
2. Implementar a funcionalidade ou correção.
3. Executar os testes disponíveis.
4. Realizar commit das alterações.
5. Enviar para o repositório.
6. Solicitar revisão dos demais integrantes.

## Testes

O projeto utiliza testes automatizados de sistema com Playwright.

Para executar os testes:

```bash
cd frontend
npx playwright test
```

## Registro de Problemas

Bugs, correções e melhorias devem ser registrados através das Issues do repositório.
